# Волшебный вестник

Основной адрес: https://volshebny-vestnik-ar-2026.onrender.com .

Статический мобильный сайт: HTML, CSS, JavaScript, локальный MindAR, MP4 и маркер распознавания. Камера обрабатывается на устройстве посетителя. Аккаунт ChatGPT не требуется; платформенная обёртка прежнего хостинга удалена.

## Публикация

Render Static Site, ветка main, папка site, команда `sh scripts/build-static.sh`. Переменная `SKIP_INSTALL_DEPS=true`. Изменения в main автоматически публикуются Render.

Исходный MP4 хранится четырьмя частями из-за ограничения размера запроса подключения. Сборка соединяет их без перекодирования и проверяет SHA-256 по media_parts/video.sha256.

## QR и анимация

QR в афише и видео ведёт на основной адрес Render. Остальные пиксели афиши сохранены, исходная фотография для распознавания не менялась. Сохранены дата 26 декабря, 19:00, цены из утверждённого макета, медленные цепочки букв, ученик на метле и снич. Кэш ресурсов обновлён до v8.

## Бесплатное размещение

Статический сервис Render не имеет абонентской платы. Используются включённые в рабочее пространство квоты трафика и минут сборки. Платные дополнения этому сайту не требуются.
