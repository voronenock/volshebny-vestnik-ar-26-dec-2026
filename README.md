# Волшебный вестник

Основной адрес: https://voronenock.github.io/volshebny-vestnik-ar-26-dec-2026/

Статический мобильный сайт оживающей газеты: HTML, CSS, JavaScript, локальный MindAR, MP4 и маркер распознавания. Камера обрабатывается на устройстве посетителя; аккаунт ChatGPT не требуется. Пользователь подтвердил, что основной адрес работает без VPN.

## Публикация

GitHub Pages через .github/workflows/pages.yml: сборка sh scripts/build-static.sh, папка site. Изменения main автоматически публикуются. Копия на Render сохранена.

Исходный MP4 хранится четырьмя частями из-за ограничения размера запроса подключения. Сборка соединяет исходные байты без перекодирования и проверяет SHA-256 по media_parts/video.sha256.

## QR и анимация

QR в афише и видео ведёт на основной адрес GitHub Pages. Остальные пиксели афиши сохранены, фотография для распознавания не менялась. Сохранены дата 26 декабря, 19:00, цены актуального макета, медленные цепочки букв, ученик на метле и снич. Кэш ресурсов обновлён до v9.

Платные сервисы, платёжные данные и настройки оплаты не менялись.

## Двусторонний билет

Адрес: https://voronenock.github.io/volshebny-vestnik-ar-26-dec-2026/ticket/

Обе стороны имеют отдельные анимации и маркеры в ticket.mind. Фотография на лицевой стороне: [752,162,1388,772], на обороте: [640,158,1334,762], полный размер каждой стороны 1870 × 841 px. Оба нативных видео запускаются нажатием до запроса разрешения камеры; распознанная сторона выбирает нужное видео и свою геометрию наложения. Имена и отметки бара находятся вне изображений распознавания.

Печать: site/ticket/bilety_A4_dvustoronnie.pdf, A4, две страницы, три билета 190 × 85.45 мм. Двусторонняя печать, переворот по длинной стороне листа, масштаб 100%. Эффективное разрешение 250 ppi.

Регенерация: python3 tools/prepare-ticket.py site/ticket/bilet_yolka.png site/ticket/bilet_oborot.png; python3 tools/prepare-ticket-motion.py; node tools/render-ticket.mjs; node tools/render-ticket-back.mjs. Для сборки маркеров tools/compile-ticket-targets.mjs использует AR_BUILD_TOOLS с mind-ar 1.2.5, @tensorflow/tfjs 4.16.0 и canvas (@napi-rs/canvas 0.1.80). Камера и просмотр не требуют платной подписки или аккаунта ChatGPT.

Проверка логики двух сторон: node --experimental-vm-modules --test tests/ticket-ar.test.mjs. Геометрия и переключение проверяются автоматически; распознавание напечатанного билета и точность совмещения нужно подтвердить на физическом телефоне.
