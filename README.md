# Волшебный вестник

Основной адрес: https://voronenock.github.io/volshebny-vestnik-ar-26-dec-2026/

Статический мобильный сайт оживающей газеты: HTML, CSS, JavaScript, локальный MindAR, MP4 и маркер распознавания. Камера обрабатывается на устройстве посетителя; аккаунт ChatGPT не требуется. Пользователь подтвердил, что основной адрес работает без VPN.

## Публикация

GitHub Pages через .github/workflows/pages.yml: сборка sh scripts/build-static.sh, папка site. Изменения main автоматически публикуются. Копия на Render сохранена.

Исходный MP4 хранится четырьмя частями из-за ограничения размера запроса подключения. Сборка соединяет исходные байты без перекодирования и проверяет SHA-256 по media_parts/video.sha256.

## QR и анимация

QR в афише и видео ведёт на основной адрес GitHub Pages. Остальные пиксели афиши сохранены, фотография для распознавания не менялась. Сохранены дата 26 декабря, 19:00, цены актуального макета, медленные цепочки букв, ученик на метле и снич. Кэш ресурсов обновлён до v9.

Платные сервисы, платёжные данные и настройки оплаты не менялись.

## Двусторонний билет и новый фильм

Адрес: https://voronenock.github.io/volshebny-vestnik-ar-26-dec-2026/ticket/?v=2

Печатный оборот упрощён: общий номер 2612, без имени, пустых строк и отметки о напитке. Условия напитка сохранены: со стаканчиком «Хогвартс» посетителю бесплатно нальют лимитированный напиток на баре.

Новый фильм длится 24 секунды и создан как отдельная 3D-сцена: Большой зал с длинными столами и едой, парящие свечи, говорящая Распределяющая шляпа, дуэль летающих палочек, заклинания, левитация блюд и книги, финал с чашкой Хогвартса и информацией о напитке. Авторская сцена моделируется и анимируется tools/render-hogwarts-scene.py (Blender 4.3.2, Workbench); свечение, заклинания и точная кириллица добавляются tools/compose-hogwarts-film.mjs. Фильм 960 × 432 px, 18 кадров/с, H.264, без звука. Подписки и внешние платные генерации не использовались.

Обе стороны открывают один фильм. При перевороте билета меняется геометрия наложения, время фильма сохраняется. Два изображения распознавания объединены в ticket.mind; лицо [752,162,1388,772], оборот [640,158,1334,762], полная полоса 1870 × 841 px. Видео запускается нативно в нажатии пользователя до запроса доступа к камере.

Печать: site/ticket/bilety_A4_dvustoronnie.pdf, A4, две страницы, три билета 190 × 85.45 мм. Двусторонняя печать, переворот по длинной стороне листа, масштаб 100%, эффективное разрешение 250 ppi.

Проверка логики: node --experimental-vm-modules --test tests/ticket-ar.test.mjs. Распознавание напечатанного билета и совмещение нужно подтвердить на физическом телефоне перед тиражом.
