# Волшебный вестник

Статический сайт оживающей газеты. Камера обрабатывается на устройстве посетителя. HTML, CSS, JavaScript, MindAR, видео и маркер хранятся вместе; серверная часть и аккаунт ChatGPT посетителю не нужны.

## Публикация

- Тип сервиса: Static Site.
- Ветка: main.
- Команда сборки: `sh scripts/build-static.sh`.
- Папка публикации: `site`.
- Переменная: `SKIP_INSTALL_DEPS=true`.

Видео разделено на четыре части для передачи через подключение. Сборка соединяет исходные байты и проверяет SHA-256. Перекодирование и изменение анимации не выполняются.

## Текущий статус переноса

Рабочее пространство Render ещё не подтверждено владельцем, внешняя публикация не создана. После выдачи окончательного URL нужно заменить QR в афише и видео и повторно опубликовать. Сейчас QR ведёт на прежний адрес.

## Бесплатное размещение

Статические сайты Render не имеют платы за сам сервис, но используют включённые трафик и минуты сборки. При превышении квоты и наличии платёжного средства возможна оплата. Бюджет этого переноса — 0 ₽; не включайте платные функции и сначала подтвердите условия отсутствия списаний.

Все файлы в `site` взяты из проверенной опубликованной версии мобильного сайта. Платформенная обёртка прежнего хоста удалена; исходный HTML сохранён.
